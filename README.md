# SPAF Masterclass 2026 Quiz

Clinical AF challenge for the SPAF Masterclass. Same quiz engine and Supabase project as Mysteries of the Gut — copy and URL only changed.

Deployed at [masterclass-spaf-quiz.vercel.app](https://masterclass-spaf-quiz.vercel.app). Use

```bash
yarn
yarn dev
```

Copy `.env.example` to `.env` and use the existing Mysteries of the Gut `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY`.
